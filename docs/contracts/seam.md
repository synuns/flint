# Seam 사용 규칙

Sources: v1.32.0 스펙 M3(seam 규칙 명문화) · `docs/TUNING.md`.

## 규칙

1. **var func seam(`var XxxFn = ...`)은 프로세스 경계 한정** —
   compose/exec/http 호출처럼 프로세스 밖과 만나는 지점에만 쓴다.
2. **신규 내부 로직은 인터페이스 주입 우선** — 같은 프로세스 안의
   테스트 대체 지점은 파라미터·인터페이스 주입으로 만든다.
3. 기존 인프로세스 var func seam은 예외로 명목 등록하고 점진
   축소한다(예: mcp→cli 재진입 — `docs/contracts/engine.md`).

## 근거

var func seam은 패키지 전역 상태라 등록 순서·병렬 테스트에서
간섭을 만든다. 프로세스 경계는 어차피 비동기·외부 상태가 지배하는
지점이라 seam 비용이 상쇄되지만, 내부 로직에서는 인터페이스 주입이
같은 대체성을 간섭 없이 제공한다.
