## 필수 요구사항

1. **Homebrew 배포**: brew tap 설치 경로 — formula 작성(release
   바이너리 다운로드·checksum 검증)·README 설치 절 갱신·
   tap 저장소 준비 지침(사용자 계정 레포 — 문서로 가이드).
2. **신뢰 아티팩트**: release 첨부 checksums.sig 절차 문서화·
   (가능 시) workflow에 서명 단계 — 기존 release 자산 구조 조사.
3. **README 국제화 정비**: EN README를 원전으로 KO 정합 재검토·
   설치·퀵스타트 절 보강(3커맨드 이내 첫 성공 경험)·아키텍처
   다이어그램 추가(텍스트 다이어그램).
4. **커뮤니티 기반**: CONTRIBUTING.md(기여 절차·make ci 로컬
   검증 안내)·ISSUE 템플릿(버그·기능)· 최소 CHANGELOG 링크.
5. **문서**: HISTORY·계약행 TestVersion01500Milestone·release-gate.
