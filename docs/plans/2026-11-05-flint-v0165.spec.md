# flint v0.16.5 스펙 — setup --mcp 자동 하네스 등록·MCP Registry 준비

- **날짜**: 2026-11-05 · **상태**: 기획 완료 · **오케스트레이터**: AI(사용자 지시 "등록 해보자" + setup --mcp, PR 머지까지 자율)
- **이전**: v0.16.4(release 잡 멱등 가드)

## 1. 배경

- **하네스 배포 현황**: Claude Code만 마켓플레이스 존재, 나머지 5종
  (codex·gemini·opencode·copilot·cursor)는 전부 수동 설정 파일 편집.
  그러나 **전 하네스에 네이티브 `mcp add` CLI 존재**(실측: codex·
  gemini·opencode 확인, cursor·copilot는 문서 기준) — flint이 직접
  호출해 원라인 등록 가능.
- **MCP Registry** (registry.modelcontextprotocol.io 공식, preview):
  무료·사전 심사 없음·발행 즉시 검색 가능. Go 바이너리는 .mcpb
  아티팩트 → GitHub Release URL + SHA256. `mcp-publisher` CLI로 발행
  (사용자 GitHub OAuth 필요 — 본 스펙은 준비까지만, 발행은 안내).

## 2. 목표·비목표

목표: R1–R3. 비목표: Smithery(Streamable HTTP 필수 — stdio flint

## 3. 요구사항

### R1 setup --mcp (자동 하네스 등록)
- `flint setup --mcp` — 설치된 하네스 자동 탐지(exec.LookPath) 후
  각자의 네이티브 CLI로 MCP 서버 등록:
  - codex: `codex mcp add flint -- flint mcp`
  - gemini: `gemini mcp add flint flint mcp`
  - opencode: `opencode mcp add flint -- flint mcp`
  - cursor: `cursor mcp add flint flint mcp` (설치 시)
  - copilot: 설정 파일 경로 안내만(CLI 미검증)
- 이미 등록된 하네스는 스킵(중복 방지 — 사전 `mcp list` 확인 또는
  등록 에러 무시). 미설치 하네스는 조용히 스킵.
- 결과: `{"status":"ok","registered":[...],"skipped":[...]}` 한 줄 JSON.

### R2 .mcpb 아티팩트 + goreleaser
- .mcpb 번들: flint 바이너리 + manifest.json(MCP 표준 형식 — 조사:
  mcpb는 사실상 zip이며 내부에 manifest.json + 바이너리)을 플랫폼별
  생성. goreleaser extra_files 또는 post-build 스텝으로 Release 자산에
  `flint_<version>_<os>_<arch>.mcpb` 추가.
- 기존 tar.gz·plugin zip 불변.

### R3 server.json + 발행 안내
- `mcp-registry/server.json` — MCP Registry 등록 메타데이터(스펙:
  name "io.github.synuns/flint"·description 100자 이내·mcpb 패키지
  타입·GitHub Release URL + fileSha256 [버전 플레이스홀더]).
- README에 발행 절차 3단계 안내(brew install mcp-publisher → login
  github → publish — server.json 사용).
