# flint v0.15.1 스펙 — 패치: e2e 침묵 계약 잔존 청산

- **날짜**: 2026-11-05 · **상태**: 기획 완료 · **오케스트레이터**: AI(패치 전용 루프 이터레이션 1 — 사용자 지시, PR 머지까지 자율)
- **이전**: v0.15.0(PR #26 머지·태그 — 태그 CI는 v0.14.0부터 e2e 레드 상태)

## 1. 배경

- v0.14.0 제로히트 exit 1 계약 전환 시 e2e `TestReadEscapesLikeWildcards`
  의 주입 시도 케이스(`%' OR '1'='1` — "오류 없이 빈 결과" exit 0
  단얱)가 누락됐다. 해당 read는 이스케이프 정상 작동으로 제로히트 →
  v0.14.0부터 exit 1·무출력이 정상 동작. 결과: 태그 CI(make e2e)가
  v0.14.0·v0.15.0 연속 레드.
- 프로세스 원인: PR 즉시 머지로 CI 레드 미관측. 루프 규칙 승격
  (머지 전 CI 그린 대기 — 운영 기록, 코드 밖).

## 2. 목표·비목표

목표: R1–R2. 비목표: e2e 재구조·assertRead 헬퍼 일반화(필요 최소)·
CI 파이프라인 변경(workflow는 이미 e2e 실행 중)·기타 기능.

## 3. 요구사항

### R1 e2e 주입 케이스 계약 정합
- `assertRead(`%' OR '1'='1`, "", 0)` — assertRead 헬퍼의 exit 0
  강제와 충돌. 주입 시도 케이스를 헬퍼 밖 직접 단얱으로: **exit 1·
  출력 완전 무**(침묵 계약 — 에러 JSON 부재로 "오류 없음" 의도 승계,
  매칭 0건으로 인젝션 무효 의도 승계). 나머지 4개 assertRead 케이스
  (히트 경로) 불변.
