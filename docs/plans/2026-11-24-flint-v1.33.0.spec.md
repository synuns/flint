report --serve가 유일한 사람용 시각 표면이 되는 에이전틱 기반 구축 +
수집 단절 자기감시 5종(doctor 확장). 데이터·스키마 v19 유지 — 기존

- ETag 3원칙: `lib/cli/update.go`(조건부 재검증·모순 검출기·

  프론트 자산 embed는 같은 관례(html/template 산출물 포함).

  본 릴리스에 반영.

## 1. 마일스톤

### M1 serve 서버 (동일 Diagnose 원천)

- `flint report --serve` — localhost(127.0.0.1) 한정 HTTP 서버. 명시
  실행만·세션 흐름 무간섭·Ctrl-C 종료. 엔진 연결은 요청 단위 처리
  (장기 점유 방지 — v1.29.0 footprint 원칙 정합).
- 엔드포인트: `/api/diagnose.json`(전체)·`/api/sections/<area>.json`
  (5영역별) — 응답은 render 조크포인트(살균 단일 출구)를 경유 강제,
  원시 값 직접 노출 금지.
- ETag·조건부 재검증(If-None-Match → 304) — 표면 신뢰 3원칙 재사용.
- 기존 채널(JSON·text·TUI) 무변경.
- 계약 동반 — 커맨드 표·usage 등록(`report --serve`·`--port`)·
  docs-sync(PLAN 4뷰 갱신·QUICKSTART·RUNBOOK 해당 행).

### M2 HTML 골격 + 임시 디자인 슬롯

- Go `html/template` 시맨틱 골격 — `<section data-area="...">` 5영역
  (지식 위생·회상 품질·토큰 경제·자율 튜닝·엔진 운영). 골격 순서는
  나열 순서, 최종 순서는 디자인 트랙 재판정.
- CSS 변수 훅(`--flint-*`) + hand 토큰 임시 CSS — 스타일 교체만으로
  갈아끼우는 슬롯 구조(디자인 착수 후에도 에이전틱 산출물 유효).
- vanilla fetch(수동 갱신 기본·폴링은 옵트인). htmx는 구조 변경 없이
  추가 가능한 옵션 유지.
- React·Node 런타임·무거운 차트 라이브러리 금지 유지.

### M3 폐기 전환

- `--html/--out` → deprecated(경유 동작 유지·마이그레이션 안내 동반).
  정적 `dashboard.tmpl.html` 경로는 serve 경유로 대체 폐기 — 관련
  테스트·문서 계약 행 갱신. 완전 제거 시점은 전역 미결정(실측 후).
- PLAN §7 "대시보드 동적 서버" 비목표 해제 본문 반영·4뷰 원칙 →
  "2뷰 + serve — 동일 Diagnose 원천" 갱신.

### M4 영역 F — doctor 확장 5종 + METRICS 총목록

1. 훅 경로 해석 검증 — 훅이 호출하는 실행 경로(flint 바이너리·
   플러그인 스크립트)의 존재·해석(등록 검사와 별개).
2. config DSN 유효성 — engine_url·port 접속 실패 분류(엔진 다운 vs
   DSN 결함 구분).
3. 수집 신선도 경고 — 최근 세션 흡수(session_starts) 임계 무기간
   시 경고. 신호로만·사용 패턴과 구분(A4 관례 승계).
4. 플러그인-CLI 버전 격차 경고 — 설치 플러그인 버전과 CLI 버전의
   마이너 격차 임계 초과.
5. 서비스 잔재 감지 — launchd·systemd user label이 임시 디렉터 경로
   등을 지칭하는 잔재 탐지(v1.31.0 서비스 등록표 승계).
6. METRICS 원천 데이터 총목록(영역 F §3.1 — 사용자 결정 편입) —
   METRICS.md에 이벤트 테이블·daily counter 키 전수(진실 원천 =
   `lib/db/usage.go` MeteringKindRegistry)·수집 조건·보존 기간을 한
   표로 신설 + 스테일 5키 정정(correction_preference·correction_fact·
   merge_audit_pairs·recall_audit_listed·recall_audit_disposed).
- 전 체크: 감지만 + 복구 명령 안내(자동 실행 금지 — 비간섭·파괴 방지).
