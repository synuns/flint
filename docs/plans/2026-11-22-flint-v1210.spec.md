## 계약

### 스키마 v16 (additive — EnsureSchemaV16)

1. `vault_files(id bigserial PK, path text NOT NULL UNIQUE, title text NOT
   NULL, tags text NOT NULL DEFAULT '', mtime timestamptz NOT NULL, size
   bigint NOT NULL, content_hash text NOT NULL, summary text NOT NULL
   DEFAULT '', last_indexed_at timestamptz NOT NULL DEFAULT now())` +
   인덱스 `(content_hash)`. auditStageTables 등록·Repo.Commit("index:
   vault files=N changed=M") — 스캔 1회=배치 1커밋(디프 전체 1tx+Commit).
2. 디프: 1차 필터 DB (mtime,size) 불일치 → sha256 재계산·변경 행 UPDATE가
   아닌 신규 행 INSERT? **아니오 — path UNIQUE UPSERT**(행 갱신·append-only
   원칙은 knowledge 한정). 삭제: DB 유·스캔 무 path DELETE(NOT IN MIN 형태
   — DELETE…USING 미지원).
3. thresholds 3종 — `vault_scan_max_files`(10000)·
   `vault_summary_max_runes`(200)·`vault_skip_dirs`(문자열 —
   parseStringOrDefault 신규·쉼표 구분·기본 ".obsidian,.trash"). 등록
   5곳+TUNING §2+guard 키 집합.
4. 게이트 체인: EnsureSchemaV16·레지스트리·LatestSchemaVersion 15→16·
   schema.sql 종착상태·Contiguous/CoverAdmin.

### `flint index [--vault PATH] [--limit N]`

- WalkDir + `.md` 전용 + skip dirs. --limit=0 무제한 기본·초과 시 "N
  skipped — rerun" 안내. --vault 미명시 시 meta vault_path 사용·부재 시
  exit 3 안내. 경로는 사용자 명시 원칙(자동 탐지 금지). 볼트 경로 로그·
  문서 비인용(개인 정보).
- 산출 JSON: scanned·changed·new·removed·skipped·duration. status에
  볼트 색인 상태 행(마지막 색인 시점·파일 수·변경 감지 수 — 기존 키
  순서 불변·append).

### read 통합 (M2)

- 별도 쿼리 `title||summary||tags LIKE` → ReorderByFallbackCount 앱사이드
  퓨전에 vault 소스 신호 추가(또는 결과 하단 vault 섹션) — **지식 행
  집합·상호 순위·직렬화 불변·vault 행은 지식 행 이후에만 삽입**·상한

- read 응답에 vault 행은 id 대신 path 식별·`source:"vault"` 표기.
