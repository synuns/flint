## 1. 목표·위상

지식 파이프라인 5영역(추출·저장·유지보수·검색·전달)의 체계 완결.
저장은 성숙(v19·bi-temporal·links) — 본 문서는 추출·전달·유지보수의
조사 기반 후보와 검색 재판정을 다룬다. README 정면 핵심 가치의 원천.

## 2. 근거 (조사 일반 서술)

- 쓰기 시 갱신/삭제 판정이 빠지면 저장소가 부패한다는 외부 실증 —
  flint echo 구조의 정당성·계약 명문화 가치.
- 고정 규칙은 강한 모델에서 역효과·재도출 가능한 정보는 저장 무의미·
  노트 교정의 ground truth는 원본 — 형성 휴리스틱의 근거.
- 신뢰 tier + 하향 한정 confidence의 독립 선행 — K2와 동일 구조.
- 주입 최소와 능동 회상의 좁은 예외가 쌍으로 실증 — 전달 설계의 근거.
- 외부 벤치마크의 합성·블랙박스 한계 — 자기 평가(영역 I) 방향 근거.

## 3. 추출 후보

1. **echo 계약 명문화** — 근사 스캔 선행→NOOP>삭제>갱신>추가 위임.
   판정 우선순위를 계약 문서·테스트로 고정.
2. **재도출 가능 정보 저장 금지 휴리스틱** — 원본(source_path·해시)
   존재·일치 시 파생 계층(인덱스)으로 분류, 독립 지식은 원문 유래
   없는 것만. write 검증의 결정론 규칙. **분기 결정(2026-11-24 사용자
   확정): 파생 태깅 후 저장** — 원본 근거 연결·회상 우선순위 하향.
   오분류 시 정상 지식 유실을 피하며, 완전 중복은 기존 content_hash
   dedup(NOOP)이 담당한다. 쓰기 거부 분기는 기각.
3. **규칙형 지식 근거 동봉 강제** — 절차·조건부 지식은 source·검증
   상태 필드 동봉(필드 존재 검사 = 결정론 검증).
4. **신뢰 tier 등록표** — source 채널별 tier(meta 오버라이드)·
   confidence는 tier 내 하향만 가능(무검증 자동 승격 금지 — K2).
5. **kind 분리 근거 편입** — 에피소드/의미/절차 유형별 그래뉼러리티
   차이의 학술 근거를 스키마 발전 계열에 반영.

## 4. 전달 후보

1. **주입 최소 실증 문서화** — context rot 근거로 "효과 주장"→
   "실증 원칙" 승격 + 주입량-성능 상관 계측.
2. **이벤트 트리거 한정 능동 회상** — 세션 시작 1회·조건 파열 시만.
   비간섭과 양립하는 좁은 예외(질문 없는 시나리오 실증 대응).
   **경로 결정(2026-11-24 사용자 확정): session-start 흡수** — 새 훅
   추가 없이 기존 session-start 1회 응답 안에서 재점검 큐·stale
   경고급 항목만 주입. 조건 파열 = 기존 재점검 큐 조건(조건 태그·
   stale 증거). UserPromptSubmit 확장·별도 훅은 기각. 주입량은 기존
   토큰 예산 회계(hot 예산 등) 경유 — 예산 밖 추가 주입은 비간섭
   위반(2026-11-24 자체 리뷰 보강).
3. **provenance 노출 강화** — 회상 행별 출처·신뢰도 표시(--why 계열).
4. **abstention 자기 채점** — zero-hit 분해를 "모른다고 말하는 정확도"
   지표로 정식화.
5. **비파괴 합성 스토어** — Anthropic Dreams 패턴(입력 스토어 불변·
   새 스토어 산출·검토 후 채택) — summary-only 회상의 안전한 형태.

## 5. 유지보수·재판정

- **census** — 데코이·센티넬(선행 사례 미발견·신규 기여 영역).
  echo·재점검 정착 후 착수 원칙 승계.
- **검색 시맨틱 재판정(별도 ADR)** — 로컬 임베딩 파일(SQLite-vec·
  ONNX 계열)이 T2 "외부 LLM 의존" 정의에 포함되는가. 트리거: 계기판
  (영역 A)이 회상 품질 한계를 실측으로 보여줄 때.
- **채택 불가(조사 확정)**: 불투명 합성 프로필 자동 주입(P2·K4 위반)·
  상시 관찰 자동 적립(비목표 "발언 전량 캡처" 위반)·모델 훈련 의존
  방어(결정론 위반 — 쓰기 경계 부분만 채택).

## 6. 미결정 (착수 시 결정)

- 교정 입구 A안(하니스 훅 확장) vs B안(에이전트 계약 유도) —
  영역 D(AX 점검) 결과를 입력으로 결정
- echo 상위 k·스코어 컷 thresholds 키 명명(기존 §6 룰링 승계)
- 비파괴 합성 스토어의 스키마(additive 게이트 — G2 확정)
- **스키마 확장 원칙(2026-11-24 리뷰 룰링)** — 신뢰 tier·근거 동봉은
  기존 컬럼(source·tags·confidence)·meta 등록표 소화를 먼저 시도,
  불가 시 additive 1회 마이그레이션으로 G2에서 확정
- **재도출 판정 기준(2026-11-24 자체 리뷰)** — "원본 존재·해시 일치"의
  판정 대상(vault 원본 vs source_path 지식)·검사 비용·echo NOOP
  (정확 중복)과의 경계. 오분류 시 정상 지식이 파생 태깅되는 회귀
  테스트 동반
- **비파괴 합성의 합성 주체(2026-11-24 자체 리뷰)** — 결정론(T2) 안에서
  "합성"의 정의(결정론 재구성·클러스터 요약 등). LLM 합성이 전제되면
  검색 시맨틱 재판정 ADR로 통합 재판정
