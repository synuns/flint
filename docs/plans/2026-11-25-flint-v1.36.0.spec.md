## 1. 마일스톤

### M1 echo 계약 명문화

- **실물 위계를 그대로 문서화**: write.go 현재 흐름 = 배치 seen-dup →
  content_hash NOOP(emitDuplicate) → echo 어드바이저리 스캔(duplicates/
  contradicts 보고) → Classify → 추가(2분기) — 동작 변경 금지·드리프트
  시 고정 계약 테스트 red.
- **NOOP>삭제>갱신>추가는 영역 B 계약 어휘**(위임 대상 언어)로 병기 —
  삭제=maintain/invalidate 경로·갱신=approve/pending 경로·NOOP=emit
  Duplicate·추가=Classify 통과. 고정 테스트는 실물 2분기+위임 어휘
  대조로 작성(가상 4분기 분기 검사 금지 — 동작 변경 강제 방지).
- 경계 케이스 표: 근사 스캔 threshold·topic 일치·이유(reason) 필드.

### M2 재도출 파생 태깅 후 저장 (사용자 확정)

- write 검증의 결정론 규칙: 원본(source_path·해시) 존재·일치 시
  **파생 태깅 후 저장** — origin은 원본 근거 연결·회상 우선순위 하향
  태그 경유(origin 값 하향 아님·스키마 불변).
- **검사 비용**(Ruling): 기존 content_hash 1회 조회+기존 echo 스캔 한도
  내 — 신규 전수 스캔 없음.
- 오분류 시 정상 지식 유실 방지 회귀 테스트(원본 없는 신규 지식이
  파생 오분류되지 않음)·echo NOOP(정확 중복)와의 경계 테스트.
- 판정 대상·검사 비용·경계는 영역 B §6 미결정 항목의 확정안을 §2
  Ruling으로 제시.

### M3 규칙형 근거 동봉 강제

- 절차·조건부 지식(규칙형)은 **origin(또는 source_path)·status 필드
  동봉 강제** — source는 CLI 플래그이며 payload 키는 finalizeRec에서
  유실되므로 대상 아님. 필드 존재 검사 = 결정론 검증(write 게이트·
  구조화 실패 출력 계약 준수).
- 판정 기준: 태그·컨텐츠 신호의 결정론 조합(문서화·테스트).

### M4 신뢰 tier 등록표

- source 채널별 tier 등록표(meta 오버라이드 가능 — thresholds 관례)·
  confidence는 tier 내 하향만 가능(K2 무검증 자동 승격 금지 — write
  게이트: 상향 시도는 exit 3·구조화 실패 출력).
- 등록표 초기값·하향 규칙·승격 불가 계약 테스트.

### M5 kind 분리 근거 편입

- 에피소드/의미/절차 유형별 그래뉼러리티 차이의 학술 근거를 스키마
  발전 계열 문서(docs/PLAN.md §3 해당 행)에 편입 — 문서 전용·동작
  변경 없음.

### M6 교정 입구 결정 (영역 D 권고 편입)

- **B안(에이전트 계약 유도) 기본+A안(하니스 훅 확장) 한정 병행** 확정
  (영역 D 감사 권고 승계) — 결정 근거·적용 범위·A안 병행 조건을
  교정 입구 문서(계약 문서 계열)에 기록.
- v1.34.0 전달 계열(능동 회상·provenance)과의 연결 관계 명시.

## 2. Ruling (확정안 — 독립 리뷰에서 확정)

| 항목 | Ruling |
|---|---|
| echo 위계 | 코드 위계 그대로 문서화·고정 테스트 — 동작 변경 금지 |
| 파생 태깅 대상 | 원본 존재·해시 일치 시(vault 브리지 파일 기준)·파생 태그 경유(origin 값 불변) |
| 검사 비용 | 기존 content_hash 1회 조회+기존 echo 스캔 한도 내 — 신규 전수 스캔 없음 |
| echo NOOP 경계 | 정확 중복(content_hash)은 NOOP·근사 일치는 파생 판정 대상 — 두 검사 순서 고정 |
| 근거 동봉 판정 | 규칙형 신호의 결정론 조합(태그 prefix·문형)·필드는 origin/source_path·status — 등록표 경유 |
| tier 등록표 | thresholds 관례(source→tier 상한·meta 오버라이드)·하향만·승격 불가 |
| 교정 입구 | B안 기본+A안 한정 병행(영역 D 권고 승계) — v1.36.0 결정 기록 |
| kind 편집 | 문서 전용 — 스키마·동작 변경 없음 |
