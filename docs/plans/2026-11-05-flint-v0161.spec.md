## 1. 배경 — 독립 CI 리뷰(2026-11-05) findings

- HIGH-1: release 잡에 `needs: test` 없음 — 테스트 실패에도 릴리스 발행.
- HIGH-2: `.mcp.json`이 `bin/flint` 상대경로 — 배포 zip에 바이너리 없어
  플러그인 MCP 기동 실패(hooks.json은 PATH라 기준 불일치).
- HIGH-3: 바이너리 darwin만 — linux 플러그인 사용자 불동작(CGO 없음).
- MED: goreleaser `version: latest` 미고정 · workflow_dispatch 부재(재발사

  validate_yaml이 release 잡 검사 못 함.

- 잡별 `timeout-minutes`(test 20·release 15).
- doltgres 이미지 검증 digest 고정(sha256:3a119bb… — v0.15.2 이후 실증된
