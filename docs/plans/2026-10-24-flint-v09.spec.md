# flint v0.9 스펙 슬라이스 — 하니스 호환 확장 (2026-10-24 레퍼런스 조사 반영)

## 1. 어댑터 문서 대상 — 사용도 순 (조사 종합, 2026-10)

Claude Code(1위·이미 플러그인 지원)를 제외한 상위 5종:
1. **Codex CLI** — ChatGPT 통합, 터미널 에이전트 2위(사용도 조사 E1).
2. **Gemini CLI** — Google 계정 무료, 사용층 최대급(E1·E2).
3. **GitHub Copilot CLI** — GitHub 생태계 기본 에이전트(E3).
4. **OpenCode** — 오픈소스 CLI 급성장(E4).
5. **Cursor agent CLI** — IDE 1위의 CLI 에이전트(E2).

후순위(문서 미작성·근거만 기록): Windsurf·Amp·Goose·Crush는 MCP 지원하나
사용도 하위, Aider는 MCP 미지원이라 CLI 간접 참여만 가능(제외, E5).

## 2. 하니스별 검증된 설정 계약 (조사 인사이트)

- **C1 Codex**: `~/.codex/config.toml` → `[mcp_servers.flint]` +
  `command = "flint"` / `args = ["mcp"]`. 선택: `startup_timeout_sec`,
  `tool_timeout_sec`, `requires_approval = "never"`(기본 "untrusted"는
  도구마다 승인 — 자율 기록에 방해되므로 문서 권장값). 지시파일: AGENTS.md.
  세션 훅 없음(notify는 알림 전용 — 비목표).
- **C2 Gemini CLI**: `~/.gemini/settings.json`(글로벌) 또는
  `.gemini/settings.json`(프로젝트) → `mcpServers.flint`
  {command, args, trust:true} — `trust` 누락 시 도구 승인 다이얼로그.
  지시파일: GEMINI.md(계층적), 최신은 AGENTS.md도 인식. 세션 훅 없음.
- **C3 Copilot CLI**: `~/.copilot/mcp-config.json`(또는 대화형 `/mcp add`).
  지시파일: `~/.copilot/instructions.md`·저장소 AGENTS.md. MCP 도구는
  기본 승인 게이트 — allowlist 안내 필요. 서버 instructions 미반영
  버그(E6) → 지시파일 경로 필수 병기. 훅 없음.
- **C4 OpenCode**: `~/.config/opencode/opencode.json`(글로벌) 또는
  `opencode.json`(프로젝트) → `"mcp": {"flint": {"type": "local",
  "command": ["flint", "mcp"]}}` — mcpServers 아님·command가 배열(C4a).
  지시파일: AGENTS.md. TS 플러그인 이벤트버스는 v0.9 비목표(문서 언급).
- **C5 Cursor**: `.cursor/mcp.json`(프로젝트) / `~/.cursor/mcp.json` —
  Claude와 동일 mcpServers JSON. agent CLI는 AGENTS.md 인식. 훅은 IDE
  한정 — CLI 참여는 MCP+지시파일로 충분.
- **C6 공통**: 전 하니스 MCP stdio JSON-RPC. flint 서버 등록 감지는
  설정 파일에 `"flint"` 서버명 존재 여부(문자열 매칭, 포맷 무관).

## 3. flint MCP 서버 호환 작업 (코드)

- **N1 protocolVersion 협상**(`lib/mcp/serve.go:32` 하드코딩 "2024-11-05"
  대체): initialize params.protocolVersion(문자열)이 있으면 그대로 echo,
  없으면 기존 "2024-11-05" 유지 — 기존 라운드트립 테스트(params:{})는
  변경 없이 통과해야 한다. flint의 표면(initialize·tools/list·tools/call
  응답 구조)은 버전 간 불변이므로 echo가 안전하다.
- **N2 instructions 주입**: initialize 응답에 `instructions` 필드 추가 —
  기존 어댑터 3규칙(작업 전 read·종료 전 write·주입=데이터) 문구 재사용.
  훅 없는 하니스의 프롬프트 스니펫을 서버가 자동 제공한다(Copilot은
  미반영이므로 문서에 지시파일 병기).
- **N3 ping 응답**: `"ping"` 요청 → 빈 result `{}`. 현재 -32601은
  스펙 위반(MUST respond).
- **보존**: 알림(id 없음) 무응답(`server.go:44`)은 이미 정합 — 변경 금지.

## 4. doctor 하니스 검진

- `checkHarness` 계열: C1~C5 설정 파일 각각에 대해 (a) 파일 부재 →
  검사 생략(미설치 하니스는 경고 아님), (b) 파일 있음+flint 등록 없음 →
  fail+fix 안내(문서 경로), (c) 등록 확인 → ok.
- 경로 오버라이드: 테스트 주입용 env(FLINT_CODEX_HOME 등 5종 — 기존
  FLINT_CLAUDE_HOME 패턴 승계). 비간섭: 읽기만, 수정 자동화 없음.
