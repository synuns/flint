## Ruling (리서치 권안 채택)

- **R1 Go 검사 = 일반 Go 테스트(internal/commentlint)** — go/parser
  순수 토큰 작업이라 go/analysis·golangci-lint의 타입 정보·진단 포맷이
  불필요. 의존성 0·`go test ./...` 자동 편입. x/tools 신규 의존·
  플러그인 버전핀 비용 기각(리서치 §1·§2).
- **R2 fix 도구 = scripts/csweep.go(`//go:build ignore`)** — v1.26.2
  실적 로직(AST 범위 삭제·문자열 무페이지·지시어 보존)의 repo 편입.
  `go run scripts/csweep.go` 수동 일회성 — make 편입하지 않는다
  (게이트와 수정 도구의 역할 분리).
- **R3 셸·파이썬 검사 = scripts/check_comments.py** — python은
  tokenize(COMMENT 토큰만 — docstring은 문자열이라 미대상), bash는
  라인 스캔: 1행 셔뱅 제외·따옴표 내부 제외·heredoc 본문 포함·
  `$` 직후 및 `${...}` 내부의 `#` 제외(파라미터 확장 — `$#` 등)·
  `#!`로 시작하는 토큰은 행 위치 무관 제외(임베디드 셔뱅)·
  대상은 **git 추적 .sh·.py 전수**(`git ls-files '*.sh' '*.py'` —
  scripts·scripts/verify·flint-plugin/hooks·tests 전부 포함.
  gitignore 경로는 자동 배제).
- **R4 범위 외: Makefile·compose·markdown·.github/workflows YAML** — 설정·문서는 코드가
  아니라 v1.26.3 대상 외. 재지시 시 확장.
