## 3. 요구사항

### R1 노출 프로파일
- meta 키 `exposure_profile` = `normal`(기본·미설정 포함) | `minimal`.
- `flint setup --exposure normal|minimal` — 프로파일 기록(한 줄 JSON
  보고). 무효 값 exit 3.
- `ExposureProfile(getKV) string` 판독 헬퍼 — 미설정·파손값 `normal`.
- 프로파일은 hot·nudge 동작만 분기 — 다른 명령·exit 계약 불변.

### R2 hot 요약 주입(지연 공개)
- `flint hot`(훅 --session 포함) 기본 출력:
  - normal: `[flint] 활성 M · 대기 N · 최근 결정 K — 펼치기: flint hot --full` 1줄
  - minimal: `[flint] 활성 M · 대기 N` 1줄
- `flint hot --full`: 기존 전체 출력(바이트 불변 — 프로파일 무관).
- 계측(hot_calls 등)·exit·--session 플래그 불변. 요약 줄은 전체
  출력과 동일 데이터 소스에서 카운트만 추출.

### R3 nudge 노출 분기
- normal: Stop additionalContext를 `flint: 증류 대기 — flint nudge`
  1줄로 축소(기존 긴 명령문 폐기). SessionStart 안내도 동일 축소.
- minimal: nudge 출력 없음(additionalContext 미발생). 대신 저장된
  compact 요약 원문을 `knowledge --source hook`으로 **pending 자동
  적립**(status=pending·confidence 0.5) 후 마커 자동 종결 — 에이전트
  노출 0, 승격 게이트(approve)가 품질 보완. 적립 실패는 조용히
  스킵(마커 유지 — 다음 기회 재시도).
- `flint nudge --clear` 수동 종결 경로 불변.

### R4 훅 통합(5→3)
- 신규 커맨드 `flint session-start`·`flint session-end` — 내부에서
  기존 hot+nudge / done+nudge 시퀀스를 각각 1회 실행(출력·계측·순서
  승계). hooks.json 재편: SessionStart 1엔트리(session-start)·
  Stop 1엔트리(session-end)·PostCompact 1엔트리(compact 유지).
- doctor applyHookFix·checkHookFile이 신규 3엔트리 구조를 등록·
  검증(기존 5엔트리 사용자 설정은 교체 — 백업 승계). 기존 훅 명령
 (flint hot·done·nudge·compact 직접 호출)도 여전히 유효(하위호환).

### R5 문서 동기화
- SKILL.md: hot --full 펼침 안내·프로파일 1줄. README EN/KO: 노출
  프로파일·훅 통합 1줄씩. PLAN.md §14 v0.11.0 마일스톤.
