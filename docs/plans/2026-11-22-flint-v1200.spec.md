## 계약

### 스키마 v14 (additive — EnsureSchemaV14)

1. 신규 `knowledge_links(id bigserial PK, from_id bigint NOT NULL, to_id
   bigint NOT NULL, relation text NOT NULL, created_at timestamptz NOT
   NULL DEFAULT now())` + 인덱스 2종((from_id)·(to_id)). INSERT 전용
   (UPDATE/DELETE 경로 부재 — write 원칙 승계). 계측 테이블 아님
   (audit 스테이징 — 감사 대상 — 테이블만·시퀀스는 잔류-무해 룰링
   repo.go:554 승계). 참조 무결성: from/to 존재 검사는
   쓰기 경로에서(FK 미사용 — 기존 knowledge 관례).
2. relation 어휘 등록표 — 코드 상수 4종(refines·supports·contradicts·
   duplicates)·store Normalize에서 값 검증·미등록 값 exit 3(**신규 거부
   결정 — domain 어휘는 경고형 선례(policy.go:42)·거부 선례는 colon-token
   클래스(policy.go:47·write.go rejectedTagPrefix) 준용**).
3. `knowledge.superseded_by` 인덱스 추가((superseded_by)) — 재귀 뷰·
   사이클 CTE의 탐색 축(기존 인덱스 entity·domain·status뿐). 체인
   규모 전제: 단일 체인 깊이는 희박(수십)·전체-루트 전개는 그 곱.
4. **content_hash 불변** — relations는 HashCanonical 해시에서 제외
   (hashVolatile 등록 — valid_at·ts 승계). 같은 본문+다른 relations가
   같은 해시(dedup 보존).
5. 게이트 체인: EnsureSchemaV14 + 레지스트리 + LatestSchemaVersion
   13→14 + schema.sql 종착상태 + TestSchemaGatesContiguous.

### read 필터 확장 (migration 0)

- `--min-confidence N`(0~1 실수·기본 없음) — appendReadFilters에
  `confidence >= $n`(RankOrder 정렬은 기존 confidence DESC 유지).
- `--origin agent|human` — `origin = $v`.
- 커맨드 표·usage 라인·MCP read 입력 스키마(properties 2종) 동반.
- thresholds 개입 없음(TUNING §2 명시).

### supersede 체인 가드 (migration 0)

- `maintain --supersede OLD --by NEW`·`--merge` — NEW에서 시작해
  superseded_by를 재귀 따라 OLD 도달 시 **사이클 형성 거부**(exit 1·
  진단 문구). 1왕복 재귀 CTE(WITH RECURSIVE·깊이 상한 가드)로 판정.
- NEW 상태 불문 허용 유지(행동 변경 없음 — 기존 체인 연장 시나리오
  보존).

### supersede 체인 뷰 (migration 0 — views.sql)

- 신규 뷰 `supersede_chains(root_id, id, depth)` — 경로배열 가드
  UNION ALL 재귀(무한 반복 방지 — 리서치 실측). views_hash 이중
  게이트로 재적용(스키마 버전 무관 — v0.41.0 뷰 배포 선례).
- reapplyViews DROP 문에 supersede_chains 추가(잔류 방지).
- 소비처: export_md 체인 표기(1홉 → 말단까지 `→ #N (depth d)`)·
  maintain --supersede 사이클 검사(뷰 또는 동등 CTE 재사용).
- --as-of 비노출 유지(asOfTables 무변경 — 뷰 시점여행은 차기 재검토).

### knowledge_links 쓰기·교환

- write stdin JSON에 선택 `relations` 배열 `[{"to": <id>, "relation":
  "refines"}]` — from은 적립 행 id·어휘 검증·대상 부재 시 exit 3.
  content_hash 미포함(위 4). **duplicate 경로: 본문 해시 중복 스킵 시에도
  relations는 기존 행 id(DupMeta.ID)로 적립 — 링크 유실 방지.**
- PAM 수출 일반화 — relations에 어휘 4종 동반 수출(기존 supersedes
  파생과 병기)·import 재적립(왕복) — supersedes 소비는 기존 유지.
