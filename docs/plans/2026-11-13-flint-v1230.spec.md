# flint v1.2.3 스펙 — R17 감사 수정

## 배경

R17 3각도 감사(정확성 A·보안성 B·계약 C)가 기능 사망 1건·데이터 손실
위험 1건 포함 19건 발견. 이 중 12건을 v1.2.3에서 수정하고 B3·B4는
Ruling 보류(마일스톤 잔여). 나머지(양호 판정)는 수정 대상 아님.

## 필수 요구사항

1. **회상부족 경고 부활(A1):** done 종료 경로의 recallStarvedToday가
   v1.2.0 플랫 키와 v0.42 read_events 원천을 읽는다. 구 JSON 키 의존
   제거. 종료 경로 출력·exit 불변(§13).
2. **백업 로테이션 안전성(B1):** Rotate는 flint 생성 파일명 패턴
   (`flint-<date8>-<time6>-<pid>.sql|.age`)만 삭제한다. 사용자 .sql은
   keep 집계에서도 제외.
3. **daily 나이 감사(A3):** maintain·doctor가 3세그먼트 플랫 키의 날짜를
   인식한다.
4. **병합 계보(A2):** Merge가 superseded_by를 기록, invalidated 재병합을
   거부한다.
5. **HTML exit 정합(C2):** report --html의 서버다운→2·스키마→3 매핑이
   JSON 경로와 동일.
6. **text 뷰 진단(C3):** 기본 text 출력이 Diagnosis를 Sentence()로
   인쇄. 0건 침묵 유지.
7. **docs-sync 배선(C4·C5):** release 타깃이 docs-sync에 의존.
   .PHONY 추가. 테스트 수 표기 통일.
8. **registry·MCP(B2·B5·B6):** 잔재 server.json 삭제, dispatchWrite
   kind 화이트리스트, dispatchHot session_id 잔여 제거.
9. **라벨 mtime·stopgap(A4·A5):** 라벨 채택 시 mtime 터치, kreads
   보존일 등록표 단일 경로.
10. **문서 정합(C1·C6·C7·C8):** --diag 정정, METRICS §4.6 모순 해소,
    진단 문서 신설, 잡명 갱신.
