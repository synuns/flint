   json-canonicalization) 결정성.
2. **사이드카 체크섬:** --out 시 <FILE>.sha256 자동(backup 관례·
   sha256sum 형식).
3. **기술부채:** valid_at 왕복(ExportRow·import 보존)·PAM project형
   pending 적립·import 행 수 상한(thresholds 등록 기본 100000·초과
   exit 3).
4. **문서:** 커맨드 표·HISTORY v1.4.0·계약행·PLAN v1.5 이월·README.
5. **e2e:** 실DB PAM 왕복(export→import 별도 DB→정합·체크섬).
