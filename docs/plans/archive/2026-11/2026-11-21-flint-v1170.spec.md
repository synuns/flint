# flint v1.17.0 스펙 — 에코(echo): 만남 순간 판정·관측 키

## 배경

지식 파이프라인 §6 유일 미착수 핵심 계열(사용자 제안 2026-11-19).
신규 쓰기가 기존 지식과 "만나는 순간"에 근사 이웃·모순·병합
후보를 작성 에이전트에게 제안한다. 판정 주체는 에이전트 —
echo는 후보 제안만, 확정은 승인 회로(approve --supersede).

## 필수 요구사항

1. **에코 스캔**: write 파이프라인 dedup 직후·classify 전에
   active 지식 대상 근사 이웃 상위 k(bigramDice — read 회상과
   동일 스코어) 스캔. cap 관례(suggest_scan_cap 승계)·스캔
   실패 시 echo 생략 후 정상 write(§13 비간섭).
2. **관계 구간화**: ①정확 hash = NOOP(현행 dedup 승계)
   ②BigramDiceMultiset ≥ conflict_dup_threshold(0.6) =
   duplicates 후보 ③집합 스코어 중간대 + topic 근사 =
   contradicts 후보. 외부 LLM 없음.
3. **write 응답 echo 필드**: 기존 DuplicateMetaJSON 확장 —
   `echo: [{id, topic, score, relation}]` (relation:
   "duplicates"|"contradicts"). 작성 에이전트가 판정
   (NOOP/ADD/UPDATE+supersede) — echo는 제안만.
4. **관측 키 3종**: daily flat 카운터 신규 —
   `correction_approved`(교정→approve 전환)·
   `gap_approved`(gap→approve 전환)·
   `survived_ratio`(survived 비율 스냅숏). 기존
   correction_write·gap_write와 짝. curationCounterKinds 등록.
5. **threshold 신규**: `echo_top_k`(기본 5)·
   `echo_min_score`(기본 0.3 — 스캔 하한). 기존
   conflict_dup_threshold 승계.
6. **케이스 등록표**: pipeline.go에 echo 케이스 추가
   (관측·source 없음·작성 에이전트 판정 지원).
7. **문서**: HISTORY·계약행 TestVersion01170Milestone·TUNING
   2키·RUNBOOK 에코 절·release-gate.
