# flint v1.14.0 스펙 — 파이프라인 3단계: A안 감지·검증된 성공 강화

상태: draft

## 배경

v1.12.0의 A안 조사 결과를 받아 구현한다(조사가 부정적이면 대체
범위로 survived 강화만). 케이스 매트릭스 1번(자동 감지)·4번
(검증된 성공) 완결로 파이프라인 6케이스 전 실현.

## 필수 요구사항

1. **A안 교정 자동 감지(조건부)**: v1.12.0 조사 결과가 실현
   가능(예: Claude Code UserPromptSubmit 계열 훅에서 교정 후보
   최소 추출)이면 — 자동 감지 경로 신설·비간섭 원칙(전체 발언
   캡처 금지·최소 추출·살균 경유)·B안과 동일 종점(correction
   소스). 조사가 부정적이면 본 항목은 미구현으로 종결(근거
   RUNBOOK 명시) — 스펙 유연 조항.
2. **검증된 성공(survived) 강화**: 회상된 지식이 실제 사용된
   신호(회상 후 동일 세션 재회상·에이전트 만족 신호 관측 조사)를
   decay 가중에 반영 — survived 임계 도달 시 감쇠율 완화
   (`survived_decay_relief` 신규 키·vol:immutable과 독립).
   신호 원천은 기존 계측(read_events·recall_events) 파생만 —
   신규 계측 테이블 금지.
3. **케이스 등록표 완결**: 6케이스(교정 B안/A안·회상 실패·반복·
   survived·증류·수동) 현황을 코드 등록표 또는 문서 매트릭스로
   단일 소스화 — 드리프트 가드.
4. **문서**: HISTORY·계약행 TestVersion01400Milestone·TUNING·
   RUNBOOK 파이프라인 절 완결판·release-gate green.
