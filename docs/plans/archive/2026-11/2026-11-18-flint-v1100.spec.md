# flint v1.10.0 스펙 — 품질/위생 묶음: 주석 영어화·테스트 정리·시퀀스 청소

## 배경

v1.9.0(다중 기기)까지 기능 계열 마일스톤이 이어진 뒤 남은 위생 부채를
한데 모은다. lib/** 주석은 한국어 단일 언어로 축적돼 있다(약 12,000행
— 패키지별 실측: cli 2598·knowledge 2910·ops 2572·db 1560·wire 607·
tui 620·backup 430·store 342·query 291·mcp 229·render 65·sqlfs 17).
오픈소스 패키지로서 비한국어 기여자의 진입장벽이다. R40·R41 감사와
lib/tui vet이 남긴 소형 정밀 수리, flint_verify 검증 DB의 잔여
시퀀스 누적(R40 기록 39개 — 현재 스키마 serial 컬럼은 8개뿐)도 같이
정리한다. 주석 영어화는 대형 diff이므로 **v1.9.0 스키마(v12) 안정
이후** 실행한다.

## 필수 요구사항

1. **주석 영어화(의미 보존):** lib/**/*.go(비테스트·테스트 구분
   불문)의 한국어 주석을 전부 영어로 옮긴다. 기계 치환 금지 —
   계약·근거·경고를 담은 문장은 의미가 온전히 보존되어야 한다(코드
   동작·문자열 리터럴·출력은 불변). 패키지별 분할 태스크로 진행하고
   커밋은 주석 전용 diff(gofmt·build·전체 테스트 green 전후 동일).
2. **언어 씰 게이트:** 방언 폐쇄 게이트(lib/wire/dialect_gate_test.go)
   관례를 승계한 게이트 테스트 — lib/**/*.go 주석 라인에 한글이
   남으면 file:line과 함께 실패. 문자열 리터럴·식별자는 제외(주석
   라인만 검사). 이후 한국어 주석 재유입을 영구 차단한다.
3. **R41 Low 3건 정밀 수리:** ① HISTORY v1.8.1 "audit and other
   callers" 과장 — EscapeLike 비테스트 호출은 lib/ops/audit.go:130
   유일(정의 lib/query/read.go:109)이므로 "audit"로 정정 ②
   lib/db/history.go:4-5 헤더 "asof·audit이 이직 대상" 서술 —
   v1.8.0에 이관 완료된 현재 상태와 모순, 완료형으로 정정 ③
   lib/db/asof_query.go:46-49 동치 서술의 범위를 실제 동치 범위(안내
   문구 랩 동치 — 폴백 제거 후 원본과의 행동 동치)로 정확히 좁힌다.
4. **lib/tui vet unkeyed 4건:** maintain_test.go:504·pending_test.go:855
   의 bubbletea WindowSizeMsg 구조체 리터럴 4곳을 키 필드
   ({Width: w, Height: h})로 교체 — `go vet ./lib/tui/...` 경고 0.
5. **slow 실DB 테스트 정리:** lib/db 슬로우(실DB) 계열의 런타임을
   먼저 실측한 뒤 중복 시나리오·장시간 케이스를 통합한다. 삭제되는
   케이스의 단언은 승계 통합 케이스로 옮겨져야 한다(커버리지 손실
   0). 통합 전·후 총 런타임을 실측 기록으로 남긴다.
6. **flint_verify 잔여 시퀀스 정리:** 잔여 39개의 누출원(마이그레이션
   이력에서 폐기·개명된 테이블의 시퀀스 등)을 조사해 특정하고,
   현행 스키마가 소유하지 않는 고아 시퀀스를 정리하는 경로를
   제공한다(존재 확인 후 DROP — 감사 시퀀스·telemetry 4종은 불변).
   verify-flint 스킬의 Cleanup 절에 잔여 0 검증을 추가한다.
7. **방언 게이트 패턴 확장(검토 후 선택적):** 현행 게이트는 히스토리
   질의 방언 4패턴 한정(lib/wire/dialect_gate_test.go:17-27).
   `dolt_` 접두 전반 확장의 오탐 위험(주석 외 코드 라인의 안내
   문자열·테스트 픽스처)을 검토하고, 오탐이 통제 가능하면 진단·쓰기
   방언(dolt_remotes·dolt_status·dolt_reset 등)으로 확장한다. 불가
   판정이면 근거를 게이트 파일 주석에 기록한다.
8. **문서·버전:** v1.10.0 동기 — VERSION·README EN/KO 배지·
   plugin.json·HISTORY·계약행·release-gate green.
