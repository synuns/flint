## Ruling (G2)

- **신호 ⑤는 큐잉+참조열로 시작** — age-audit 스코어 미가입(기존 분포
  회귀 방지)·bad_recall/supersede와 동급 참조열. knowledge↔vault 연결
  (source_path)은 적립 원천 부재로 **본 버전 제외 — 관측 후 v1.25.0
  재검토**(플랜 §5 승계).
- **재점검 큐 = vault_files.content_changed_at** (v17) — 신규 큐 테이블
  부재(신규 상주 부품 0)·스탬프 소거 경로는 apply에 없다(처분 소거 연결은
  knowledge↔vault 연결과 함께 v1.25.0 이월 — v1.22.1 r96 정정: 단일 열은
  A→B→A를 감지할 수 없어 해시 원복도 재스탬프되고, 큐는 v1.25.0까지
  append-only).
- **v17 통합 3열** — vault_files.content_changed_at·knowledge.distilled_at
  (NULL 허용)·knowledge.conditions(텍스트).
- **변동성 자동 분류는 제안 한정** — 결정론 매핑(확정 결정·ADR·역사→
  immutable / 버전·경로·명령·도구→volatile / 나머지→conditional 제안)·
  age-audit 보고에 부착·적립은 승인제 — **사유: immutable 감쇠 면제의 자동 부여가 승인제 원칙과 충돌**(vol:* 태그 자체는 사전 등록이라 콜론 가드 무관)·매핑 입력은 topic·tags만(origin 미사용 — 출처 신뢰 계층과 독립).
- **조건 파열은 수동 트리거** — `maintain --recheck <id>`(conditions 값
  재점검 큐행·경과 보고). 자동 감지 없음(외부 상태 — P1).
- **distill 스코어 = recall_score 기반** — survived는 v1.25.0 D계측 연동
  후 재검토(플랜 §5 미결정 해소).
- **distill 출력 계약(ADR-0018)** — 엄선 지식 마크다운 인사이트(topic·
  summary 단위·파일당 rune 상한)·**지정 폴더 한정·미지정 거부(exit 3)**·
  볼트 노트 직접 수정 금지·export --out 패턴 승계·행 단위 멱등
  (distilled_at)·render 살균·`distill_min_score` threshold.

## 계약

### 스키마 v17 (additive — EnsureSchemaV17)

1. vault_files `content_changed_at timestamptz NULL` — 스캔 디프에서
   변경된 행에 스탬프·재점검 보고 소스·**소거 경로 없음(v1.22.1 r96
   정정: 해시 원복도 재스탬프 — 단일 열은 A→B→A 무감지, 스탬프 소거는
   v1.25.0 연결 이월)**·무변경 재스캔은 유지.
2. knowledge `distilled_at timestamptz NULL`·`conditions text NOT NULL DEFAULT ''` — **conditions는 HashCanonical 해시에서 제외(hashVolatile 등록 — relations 선례)**: 같은 본문±conditions 동일 content_hash.
3. threshold `distill_min_score`(기본 1.0 — recall_score 하한) 등록
   5곳·TUNING §2.

### 낡음 회로 (M3·잔여)

- **스캔 디프 노출** — lib/vault Stats에 변경 (path·구해시·신헤시)
  목록 노출(메모리 보유 시점)·index 산출에 changed 목록 요약(무경로·
  카운트 수준).
- **content_changed_at 큐잉** — ApplyDiff에서 변경 행 스탬프·무변경
  재스캔 시 유지·해시 동일 재적용(병렬 패자 재시도) 시 기존 스탬프
  유지(v1.22.1 r96)·큐는 v1.25.0 연결까지 append-only.
- **age-audit 확장** — 참조열 "source changed" (content_changed_at
  NOT NULL인 볼트 행 존재 시 — 지식 행 참조열에 카운트 문구)·스코어
  불변(회귀 봉인)·처분은 기존 승인제.
- **`maintain --reaffirm (--id N | --ids a,b) --yes`** — valid_at=now()
  단일 UPDATE 경로·maintenance_runs 기록·usage·커맨드 표.
- **`maintain --recheck <id>`** — conditions 값 재검토 안내 보고(큐
  소비는 아니고 재점검 대상 표시 — conditions 값과 함께 age-audit에
  표시).
- **변동성 제안** — 매핑 테이블(코드 상수+CONTENT §4)·age-audit 보고
  행에 vol 제안(suggested_vol) 부착.

### distill (M4)

- `flint distill --out DIR [--min-score N]` — recall_score ≥ distill_
  min_score AND distilled_at IS NULL 행을 마크다운 인사이트로 출력·
  출력 완료 행 distilled_at 스탬프·재실행 미출력분만. **파일명: 런당 집계 1개 `insights-<YYYYMMDD-HHMM>.md`(행 id 안정 정렬)**·동일 파일 존재 시 덮어쓰기 경고(v1.22.1 r98 정정:
  덮어쓰지 않고 `-2` suffix로 쓴다 — 스탬프된 행은 재발행 불가)·살균.
  ADR-0018 작성(출력 계약·로컬 한정·ADR-0015 원격과 구분).
