# flint 평가·회귀 체계 — 영역 I (2026-11-24)

상태: draft
원천: 2026-11-24 전달·평가법 레퍼런스 조사·마스터 인덱스
준수: 합성 데이터만·테스트 엔진 격리(v1.29.0·ADR-0019 — 결번 채움은
v1.32.0 구조 청산 T6 예정·착수 시 재확인)·결정론

## 1. 목표·위상

flint 자기 회상 품질의 회귀 테스트 체계. 조사 확정: 외부 벤치마크
(LOCOMO·LongMemEval 계열)는 합성 대화·짧은 시간 지평·정답-only
블랙박스의 한계가 실증됐고, 단일 사용자 로컬 시스템의 자기 평가가
정답 방향. "회상이 좋아졌는가/나빠졌는가"를 코드 변경 때마다
결정론으로 판정하는 기반 — 대시보드(영역 A)의 지표에도 신뢰를 준다.

## 2. 스코프

1. **합성 질의 회귀 세트** — 정답을 아는 지식 시드를 합성 DB에
   적립 → 질의 세트 실행 → read 결과가 정답에 도달하는지 판정.
   v1.29.0 테스트 엔진 격리 인프라(FLINT_TEST_DSN·전용 엔진) 소비.
2. **abstention 채점 편입** — 소유하지 않은 질의에서 모른다고 말하는
   정확도(zero-hit 분해와 정합)를 회귀 세트에 포함.
3. **공용 인프라(독립 구축 — 2026-11-24 리뷰 룰링)** — 합성 회귀 세트는
   B5 센티넬·census를 기다리지 않고 v1.37.0에서 독립 구축한다. B5
   센티넬(정답을 아는 통제 질의)·census 데코이(정상 답 NOOP 통제행)·
   영역 H 포이즈닝 시나리오는 이후 이 지반의 **소비자**로 연결 —
   v1.27.0·census 트리거와의 편성 의존 없음.
4. **지표 노출** — 회귀 결과를 대시보드(영역 A)·report의 지표로
   노출(단일 소스 원칙 — METRICS 정의와 정합).

## 3. 원칙

- 결정론 판정만(비LLM judge) — 외부 벤치마크의 LLM judge 한계 회피.
- 합성 시드는 data/seed.jsonl 관례 승계·개인 데이터 미사용.
- 회귀 세트는 CI에서 실행(make ci 편입 검토)·테스트 엔진 격리 준수.

## 4. 미결정 (착수 시 결정)

- 질의 세트 규모·시드 구성(태그·도메인 커버리지)
- 판정 기준(정확 일치 vs 근사 — echo 스코어 재사용 여부)
- CI 소요 시간 상한·실행 범위(전체 vs 표본)

## 5. 편성

v1.37.0(영역 G·H와 동행). 센티넬·데코이의 실제 착수는 census·자율
튜닝(트리거 대기)과 순서 조율 — 본 영역은 합성 회귀 세트 먼저.
