## 목표

읽기·튜닝의 대화형 표면을 갖추고 한국어 사용자 경로를 열며, 테스트
부채를 청산한다. 사용자 표면: read·tuning 대화형 모드·KO 카탈로그.
스키마 변경 없음.

## Ruling (리서치 권안 채택)

- **R1 read TUI = 무인수 대화형만** — 플래그 있는 호출·비TTY·파이프는
  현행 플래그 모드 그대로(tui.go 폴백 관례 승계). v1.19.0 read 계층
  (RecordReadEvent tail)은 표현층과 무관함을 계약 테스트로 고정.
  색상은 NO_COLOR 준수·비TTY 억제·≤4색.
- **R2 tuning TUI 하이브리드** — 무인수 대화형만 TUI 우선, 서브커맨드·
  플래그 호출은 현행 유지(스크립트 호환). 위임 테스트 6건 잔여 백로그
  동시 정리.
- **R3 i18n = lib/i18n 최소 카탈로그** — 의존 0 map 카탈로그·FLINT_LANG
  환경·영어 기본. 전면 360곳이 아니라 usage·도움말·대표 오류 경로를
  우선 교체하고 나머지는 키 등록 점진(KO 카탈로그 우선).
- **R4 brew = 검토 문서만** — tap 개설은 스코프 §6대로 사용자 요청 시.
  본 버전은 비용·자동화 검토결과 문서(brews 구성안 포함).
- **R5 테스트 정리 = 통합+공유화** — 버전 접미 테스트 파일 병합
  (doctor 11·read 10·maintain 14 등 도메인별 — 실측)·중복 헬퍴 testengine/공유
  헬퍼로 공유화(대상 목록은 G3 실측). slow 스위트 구성 유지.
- **R6 이름 = 유지 재확인+BRAND.md** — 외부 동향 회수(Grafana flint 등)
  를 docs/BRAND.md에 기록. ADR-0009 승계.
- **R7 서명 재실증 = G3 1회** — 최신 릴리스 자산 cosign verify-blob·
  flint update 검증 경로 실증(linux 상관없이 로컬 공개키).
- **R8 관측 재판정 = 기준 문서화만** — 실측 금지(개인 DB). 판정 기준
  (METRICS §4 + rounds≥14·fires≥5·streak≥3)을 TUNING.md에 명문화.
- **R9 R68 정보 3건 = 항목 철회** — 원천 기록 소실(전 아카이브·이슈
  확인). 재수집은 사용자 요청 시. 상태 표 v1.28.0 행에서 분리 명시.
- **시퀀스 회수·Doltgres 업스트림 2건 = 재검 기록** — 무해 가정
  재확인·업스트림 리포 확인 후 RUNBOOK·engine-ops 플랜 표에 기록.

## 계약

### M1 표면 — read·tuning 대화형·i18n

- `flint read`(무인수) — 대화형: 쿼리 입력·결과 탐색(스크롤·상세
  전환)·lib/tui(tui.go Run·ErrTerminalRequired·FLINT_NO_TUI). 계층
  보존: 무인수 경로도 RecordReadEvent 계약 테스트 통과.
- `flint tuning`(무인수) — TUI 우선(huh 폼 재사용). 서브커맨드·플래그
  현행 유지 — 위임 경로 위임 테스트 6건 정리.
- lib/i18n — Catalog(ko·en)·T(key)·FLINT_LANG. 적용: usage 전
  46곳(ArgSpec Usage 필드 포함 — 실측)·도움말·wire.ErrLine 대표 오류 경로. KO 번역 완성.
