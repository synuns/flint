## 3. 요구사항

### R1 doctor 자가수복
- `flint doctor --fix`: hook-file fail에 한해 자동 복구. 대상 파일은
  `$CLAUDE_HOME/settings.json`(FLINT_CLAUDE_HOME 오버라이드 승계)이며
  flint 훅 5개 — SessionStart(hot·nudge)·Stop(done·nudge)·
  PostCompact(compact) — 를 **flint 바이너리 절대경로 명령**으로 추가.
- 기존 훅·다른 키 전부 불변(JSON 읽기-병합-쓰기, 배열 append만).
  이미 flint 훅이 있으면 skip(멱등, applied=false).
- 수정 전 백업: `settings.json.flint-bak-<yyyyMMdd-HHmmss>`(원본 보존).
- JSON 파싱 실패 시 복구 중단·exit 1·안내(백업도 생성 안 함).
- --fix 적용 후 해당 check 재평가로 결과 보고. 다른 fail 검사는 기존
  안내 유지(--fix 미적용 명시). doctor 기본 동작(무 --fix)은 완전 불변.

### R2 RUNBOOK 복구 절차
- docs/RUNBOOK.md에 v0.9.3 실증 복구 절차 추가: 증상(active 행수 급감·
  dolt_log와 불일치) → 원인(비커밋 raw DELETE를 dolt_add(--all) 커밋이
  흡수) → 절차 5단계(① dolt_status 작업집합 확인 ② 정크 정리+체크포인트
  커밋 ③ dolt_revert 시도 ④ 충돌 시 `INSERT INTO knowledge SELECT …
  AS OF '<직전 커밋>' WHERE id IN (…)` 선택 복원 ⑤ read·status 검증) —
  실례 커밋(jkfa904 파괴 → 001nnpn 복구) 명시.
- 세션 테이블 유실은 수용(PLAN §8)·정크는 미복원 원칙 명시.
