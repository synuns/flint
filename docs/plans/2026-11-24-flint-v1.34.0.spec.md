## 0. 리서치 요약 (내부 조사)

- session-start 본체: `lib/ops/sessionhook.go` RunSessionStart —
  RecordSessionStart → WriteSessionLabel → RunHot(hot_budget 회계) →
  RunNudge → 업데이트·유지보수 공지. 능동 회상 흡수 지점: RunHot 뒤.
- 재점검 큐: `maintain --recheck`(lib/ops/maintain_recall.go)는 단일 ID
  재검증·조건 설정기 — 벌크 파열 선별기가 아니다. stale 선별 재료는
  `--age-audit` 선별 SQL·vaultSourceChanged(같은 파일)에 존재 — 세션
  시작용 파열 선별 쿼리는 이 조합의 신규 작성이 필요하다.
- hot 예산: `hot_budget` meta(lib/knowledge/hot.go) — 바이트 회계 계약
  존재. report 진단의 hot_budget_slack 신호로 잔여 예산 관측 가능.
- --why: WhyEvidence·FormatWhyRows(lib/query/read.go) — 회상 행 근거
  노출 존재하나 **토큰·RRF 점수 증거만** 담고 source·confidence 필드는
  없다. hot_view(lib/sqlfs/views.sql)에도 두 컬럼이 없다 — provenance
  표기 단일화는 why 형식의 필드 확장(source=·confidence=)과 hot_view
  select 확장(additive)이 선행 과제다. hot·세션 시작 경로에는
  provenance 미노출.
- zero-hit: report ZeroPct(A1 계측) — abstention("모른다") 관점의
  분해·지표 부재.

## 1. 마일스톤

### M1 능동 회상 session-start 흡수 (사용자 확정 경로)

- RunSessionStart 내 RunHot 뒤, 재점검 대상(stale 경고급) 항목만 1회
  주입 (세션 시작 1회 한정). 파열 선별 쿼리는 conditions 컬럼·
  `--age-audit` 선별 SQL·vaultSourceChanged 조합의 신규 작성 — 단일 ID
  재검증기인 `--recheck`를 벌크 선별에 오용하지 않는다.
- 주입량은 기존 hot_budget 회계 공유 — **잔여 = hot_budget − 세션 시작
  hot recordBytes(런타임 산술)** 에서만 능동 회상 주입, 잔여 0이면 주입
  0 (비간섭 ① — 예산 밖 추가 주입 금지). report 진단의
  hot_budget_slack은 주간 평균 관측 신호일 뿐 런타임 게이트가 아니다.
- 파열 항목 0이면 무출력(조용함 계약)·훅 비차단·실패 시 조용한 skip.
- UserPromptSubmit 확장·별도 훅 금지(기각 확정).

### M2 provenance 노출 강화

- **why 라인 형식의 source=·confidence= 필드 확장을 단일 관례로 정의**
  (FormatWhyRows 확장 — additive·테이블 스키마 불변) + **hot_view select
  확장**(additive — 기존 컬럼 유지)이 선행.
- 세션 시작 능동 회상 행·hot 주입 행에 출처·신뢰도 표시 — 확장된 단일
  형식 경유·경로별 중복 구현 금지(render 조크포인트 경유).

### M3 abstention 자기 채점

- zero-hit 분해: zero-hit 질의의 "답변 불가" 관점 지표
  `zero_hit_unowned_pct` 산출(A1 read_events 소비 — additive 불요).
- METRICS 단일 소스에 정의 등록 + docsync 게이트 행.
- report·대시보드 지표 노출(serve HTML 지식 위생 영역 — v1.33.0 골격 소비).

### M4 주입 최소 실증 문서화+상관 계측

- context rot 근거의 "효과 주장"→"실증 원칙" 승격 문서화(PLAN·README
  해당 행 — 영어 디폴트 원칙).
- 주입량(hot bytes)-성공률(read 성공·fallback) 상관 계측 — 주간 rollup
  소비만·신규 실시간 쿼리 금지(비간섭).
- docs-sync 계약 행 동반.
