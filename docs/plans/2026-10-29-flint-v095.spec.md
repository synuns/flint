## 3. 요구사항

### R1 스킬 중복 절감
- flint-plugin/skills/flint/SKILL.md에 3규칙 추가·강화:
  ① duplicate 응답 계약 — `{"status":"duplicate","id":N}` 수신 시 그 payload의
  세션 내 재제출 금지, "이미 #N에 있음" 인지. ② 증류(distill) 전 사전
  `flint read <topic>`으로 근사 중복 확인 후 신규만 적립. ③ "작업 전 read"
  규칙 강화 — 관련 주제·파일 작업 시작 시 1회 조회.
- 기존 규칙·문서 구조 불변(추가·강화만).

### R2 넛지 문구 개선
- lib/cli/nudge.go에 read 촉진 힌트 추가 — 신규 상수 `nudgeReadHint`
  ("작업 전 flint read <쿼리> — 기존 지식 확인")를 SessionStart 안내 경로에
  병합. **기존 문구(nudgeStopDirective·nudgeStartLine)와 기존 출력 계약은
  훼손 금지** — 기존 테스트가 정확 일치면 새 라인으로만 추가.

### R3 설정 신규 생성
- applyHookFix 확장: settings.json 부재 시 최소 뼈대 `{"hooks":{flint 5훈}}`
  생성(applied=true, backup="" — 원본 없으니 백업 불필요). 부모 디렉터리
  없으면 생성. 기존 동작(파일 존재 시 merge·멱등·백업) 전부 불변.
