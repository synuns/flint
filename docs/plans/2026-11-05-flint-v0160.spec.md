# flint v0.16.0 스펙 — 릴리스 자동화·플러그인 마켓플레이스 배포

- **날짜**: 2026-11-05 · **상태**: 기획 완료 · **오케스트레이터**: AI(사용자 지시 "B+C" — 릴리스 자동화+마켓플레이스, PR 머지까지 자율)
- **이전**: v0.15.2(PR #29 머지·태그 — CI 그린 달성)

## 1. 배경 — 사용자 선택 B+C

- 릴리스 현황: GitHub Releases 최신 v0.9.2(10-27) — v0.10.0~v0.15.2는 태그만
  존재. 워크플로는 안내만 출력(비간섭 원칙 기록). 사용자가 **B(릴리스 자동화)
  + C(플러그인 마켓플레이스)** 를 지시 — 원칙 갱신 근거로 기록.
- 플러그인(flint-plugin/: hooks·skills·commands)은 로컬 설치만 존재,
  배포 경로 없음. 공식 스펙 조사(claude-code-guide, 2026-11-05) 확정:
  - `flint-plugin/.claude-plugin/plugin.json`(필수 name만, version 권장) —
    기존 hooks/·skills/·commands 디렉터리 자동 인식, **무이동·무수정**.
  - 저장소 루트 `.claude-plugin/marketplace.json`(plugins[].source:
    "./flint-plugin") — 설치: `/plugin marketplace add synuns/flint` →
    `/plugin install flint@flint`.
  - hooks.json은 이미 PATH 기반(`flint ...`) — 플러그인 배포 시 무변경
    (바이너리 별도 설치 요구를 문서로 명시).

## 2. 목표·비목표

목표: R1–R3. 비목표: 플러그인에 바이너리 번들(플랫폼 행렬 — 문서 요구로
대체)·goreleaser 체인지로그 커스터마이즈·홈브루·기존 수동 2단계 안내의
하위 호환(자동화로 대체).

## 3. 요구사항

### R1 릴리스 자동화 (B+A)
- ci.yml의 release-notice 잡을 **release 잡으로 전환**: 태그 push(v*)
  시 goreleaser(goreleaser/goreleaser-action)로 바이너리(darwin
  arm64/amd64)·체크섬·플러그인 zip을 빌드해 GitHub Release 자동 생성.
  `permissions: contents: write`. PR/브랜치 push에서는 미동작(태그 전용).
- .goreleaser.yml: 플러그인 아카이브 추가 — flint_plugin_{{.Version}}.zip
  (flint-plugin/ 일괄, .claude-plugin 포함). 기존 바이너리 아카이브·
  체크섬 불변.

### R2 플러그인 매니페스트 (C)
- `flint-plugin/.claude-plugin/plugin.json` — name "flint"·version(배지
  동기)·description·repository.
- 루트 `.claude-plugin/marketplace.json` — name "flint"·owner synuns·
  plugins[{name flint, source "./flint-plugin", description}].
- 버전 동기 계약: plugin.json version == README 배지 버전(신규 — 배지
  갱신 룰에 plugin.json 병합). 검증은 테스트로 고정.

### R3 문서·검증
- README EN/KO: 설치 섹션 갱신 — 플러그인 설치 명령·바이너리 선행
  요구(goreleaser 릴리스에서 다운로드)·릴리스 자동화 언급. 배지
  release-v0.16.0.
- PLAN §14 v0.16.0 마일스톤. validate_yaml.py: 매니페스트 2종 파싱·
  구조 검사 추가(소규모 확장).
- flint-plugin 패키지 테스트: plugin.json↔marketplace 정합 단얱(신규).

- goreleaser-action 버전·토큰 권한 변동 — 태그 v0.16.0 push로 실증

  로컬 `goreleaser release --snapshot --clean`으로 사전 검증(미설치 시

  `/plugin marketplace add`로 실증해야 완결.
