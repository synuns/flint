1. 테스트 삭제·스킵 감지 — CI에서 테스트 파일 삭제·t.Skip 수 증가·

3. vet·lint·errcheck 상시화 — make ci에 `go vet`·`make lint`·
   errcheck 편입(U1000 실증 룰링 승계 — 게이트 최소 원칙과 균형).
4. 표면 계약 가드 확장 — 필수 플래그·exit 코드 표 검증(어댑터 계약
