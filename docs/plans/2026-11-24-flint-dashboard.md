## 1. 목표·위상

사람이 flint 내부를 한눈에 확인하는 대시보드. flint는 에이전트 자율
관리 도구이므로 사람의 유일한 시야는 관측 표면이며, 본 기능은 지식
체계(영역 B)의 평가 기기다 — 독립 UI 기능이 아니다.

## 2. 결정 사항 (2026-11-24 사용자 확정)

- **리빌딩 결정(2026-11-24)**: 기존 디자인·기능 잔재를 초기화하고
  처음부터 리빌딩한다 — report --html 템플릿·기존 대시보드 잔재
  폐기, 새 대시보드(serve)가 유일한 사람용 시각 표면. report는
  JSON·text 기계 채널만 유지(4뷰 원칙은 "2뷰 + serve 대시보드 — 동일
  Diagnose 원천"으로 갱신·PLAN 본문은 해당 릴리스에서). TUI는 터미널
  보조 표면으로 무변경. **데이터·스키마 v19 유지** — 새 대시보드는
  기존 계측(v1.19 이후)을 소비한다.
- `flint report --serve` — localhost 한정 HTTP 서버. 명시 실행만·
  세션 흐름 무간섭·Ctrl-C 종료. --html/--out은 폐기(deprecated 경유·
  마이그레이션 안내 동반).
- 프론트는 `go:embed`로 단일 바이너리에 포장. Node는 런타임에
  존재하지 않는다.
- **serve 1급 표면 승격(리빌딩으로 흡수)**: 실시간 대응은 JSON
  polling(기본)→SSE(필요 시) — vanilla JS 범위. React가 필요해지는
  트리거는 실시간이 아니라 컴포넌트 복잡도이며, 그 시점에도 서버는
  Go 그대로(빌드 산출물만 embed 교체 — API seam).
- 룰링 갱신: 시각화 내재화 폐기(2026-11-18)·PLAN §7 동적 서버 비목표
  해제. **React·Node 런타임·무거운 차트 라이브러리 금지는 유지** —
  사전컴파일 단일 CSS vendor는 금지 대상 아님(§5 참조).
- **기술 스택 확정(2026-11-24)**: 백엔드 = `report --serve` + JSON
  엔드포인트(동일 Diagnose 원천) + `go:embed` 단일 바이너리. 프론트 =
  Go `html/template` 시맨틱 마크업 + CSS 변수 훅 + vanilla fetch
  polling(필요 시 SSE 확장). htmx는 디자인 통합 단계 옵션(구조 변경
  없이 추가 가능). 차트 임시 = Go 계산 SVG(계산 로직은 라이브러리
  자산으로 승계 — 뷰·템플릿 폐기와 무관). React는 전환 경로 대기(§5).
- **임시 디자인 결정(2026-11-24)**: 에이전틱 개발은 최종 시안을 기다리지
  않고 **임시 디자인**(hand 토큰·방향 v1)으로 발행한다. 시안 확정 시
  스타일 교체만으로 갈아끼우는 슬롯 구조(§4 경계 원칙·§5 인계 연결) —
  시안 도착 후 개발 이어하기가 구조적으로 보장된다.

## 3. 스코프

- 5영역 섹션: 지식 위생·회상 품질·토큰 경제·자율 튜닝·엔진 운영.
- 스키마 확장 불요 — 기존 계측 소비. thresholds에 포트 등 신규 키
  등록.
- **serve 계약(2026-11-24 자체 리뷰 보강)**: ①엔드포인트도 render
  조크포인트(살균 단일 출구)를 경유 강제 — 원시 값 직접 노출 금지
  ②ETag·조건부 재검증은 표면 신뢰 3원칙(v1.26.0) 재사용 ③serve의
  엔진 연결은 요청 단위 처리 또는 유휴 종료로 수명주기 관리(장기
  점유 방지 — v1.29.0 footprint 원칙 정합).
- **폐기 항목**: 기존 html 템플릿·--html/--out 뷰·관련 테스트·문서
  계약 행 — v1.33.0에서 마이그레이션 안내 동반 제거.

## 4. 개발 분리 (사용자 결정)

- **①에이전틱(무인 루프, 먼저)**: 서버·데이터 엔드포인트·embed
  인프라·HTML 골격(5영역 시맨틱 마크업·CSS 변수 훅)·계약 동반(
  커맨드 표·usage·docs-sync)·TDD. "기능은 다 되는데 못생긴" 상태까지 —
  발행은 임시 디자인(§2)이며 시안 대기 없이 진행한다.
- **②휴먼인루프(이후, 사용자와)**: 정보 위계·시각 언어·지표→차트
  매핑·인터랙션 — 목업·스크린샷 반복 피드백. TBD 마킹.
- **경계 원칙**: 에이전트는 구조(시맨틱 HTML)와 훅(CSS 변수)만
  남긴다. 디자인은 구조 변경 없이 스타일 교체로 완결되어야 하며,
  디자인 착수 후에도 에이전틱 산출물은 유효해야 한다.

## 5. 디자인 방향 (2026-11-24 목업 비교 사용자 확정)

- **Basecoat(shadcn 토큰) 계열 확정** — daisyUI 기각. 다크 우선·
  subtle border·rounded card·muted 라벨 + flint identity 토큰(
  불꽃 악센트 #f59e0b 출발점 — 부싯돌·hot 브랜딩 계승).
- **전제**: Basecoat의 npm 배포가 스텁(0.0.1)으로 확인 — 디자인 단계
  에서 소스 기반 1회 사전컴파일 → 단일 CSS vendor(이후 빌드 0). 확보
  절차 검증이 디자인 단계 첫 과제.
- **htmx 컴포넌트 관례**: 컴포넌트 = Go 템플릿 partial + hx-* 속성·
  섹션별 fragment 엔드포인트가 모듈 경계 — 등록표·계약 테스트로
  관리(단일 소스 관례 승계). 상태는 서버 소유(flint 대시보드 특성과
  정합). 클라이언트 상태 밀도 상승 시 React 전환 트리거(아래 경로).
- **React 전환 경로(선점 설계 — 채택 대기)**: OpenAPI-first 계약(
  oapi-codegen·TS 타입 생성·재생성-diff 게이트)·`web/` 분리·
  PocketBase 패턴(dist 선빌드·라우트 순서 규약·캐시 헤더 규약)·
  TanStack Query 폴링+ETag 하이브리드. 채택 시점 = 인터랙션 밀도
  실측 — Basecoat과 shadcn/ui는 동일 토큰 체계라 전환 시 시각 연속.
- 차트: 디자인 단계 결정(ApexCharts 테마·lightweight-charts·커스텀
  SVG 후보).
- **디자인 진행물·인계(2026-11-24)**: 방향 v1을 Pencil 캔버스(.pen —
  repo 밖 사용자 로컬 보관)와 visual companion 목업(`.superpowers/brainstorm/
  39031-1795496497/content/design-v1.html`)으로 구성 완료 — 디자인
  반복은 별도 세션에서 계속한다. 남은 디자인 과제: ①pending 행
  미리보기·다음 행동 안내(읽기 전용 유지) ②최근 bad_recall 행 목록
  ③온도 산식 정의(recall_score·age·변동성 — 기획 공백 보완) ④볼트
  브리지 상태를 지식 위생에 편입·echo 3종을 판정 분포 미니바로 축소
  ⑤용어 확정(한글 우선+기계 용어 병기 제안 중 — 단일 소스 용어표
  등록 + 계약 테스트). 시안 확정 → 스타일 교체로 v1.33.0 이후
  패치·마이너에 편입(개발 중단 없음).
