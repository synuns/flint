## 3. 요구사항

### R1 의존성 자동 관리
- `.github/dependabot.yml` — gomod(주간)+github-actions(주간) 2 ecosystem.
- CI의 mcp-publisher 다운로드를 latest→특정 버전 고정(재현성).
- VERSION 파일과 plugin.json·README 배지 동기를 위한 `scripts/bump_version.sh`
  (버전 범프 시 잊지 않도록 — 배지 누락 사고 3회 방지).

### R2 setup UX 고도화
- `flint setup` 출력을 단계별 시각적 프로그레스로 개선:
  ```
  flint setup

    ◯ Doltgres 연결…           ✓ :5434 (12ms)
    ◯ 스키마 마이그레이션…     ✓ v5 (8 tables)
    ◯ 데모 데이터 시드…        ✓ idempotent

    완료. 다음 단계:

      에이전트 등록:       flint setup --mcp
      Claude 플러그인:     /plugin marketplace add synuns/flint
      헬스체크:           flint doctor
  ```
- ANSI 색상(그린✓·레드✗·딤 세부)·단계별 스피너·완료 요약 박스.
- `--json` 플래그로 기존 JSON 출력 유지(스크립트 호환).
- 기존 `flint setup` 동작(ping·migrate·seed 안내)은 불변 — 출력 형식만 개선.

### R3 CI 파이프라인 설계 리뷰
- 현재 구조 진단·개선점 문서화:
  - PR → test (게이트) ✓
  - main push → test → deploy(VERSION→tag→goreleaser→MCP) ✓
  - 태그 push(수동 폴백) → test → deploy ✓
- 잔여 리스크: deploy 실패 시 재시도 경로·test와 deploy 사이 race
- 검증: `python3 scripts/validate_yaml.py`가 deploy 잡 구조 전수 검사.
