## 0. 철학 — 핵심 가치 (2026-11-20 확정, 보강판)

**전제**
- **P1 오라클 없음** — flint는 세계의 상태를 알 수 없다. 관측된 증거만
  안다. 모든 자동 판정은 이 전제에서 출발(증거 누적 방식만 허용).
- **P2 기억의 주인은 사용자** — flint는 관리인. 로컬 단일 사용자
  (ADR-0013)·삭제권·비간섭 5원칙의 근거가 되는 상위 전제.

**K원칙**
- **K1 현상태 가설** — 현상태에 관한 지식은 근거·조건·신뢰도를 단
  믿음이다(pending/active/superseded는 서류가 아니라 인식 상태).
  역사 사실은 정착 기록(가설 아님) — 변동성 계층의 불변 계층과 일치.
- **K2 증거 가중치·선호/사실 분기** — 증거 종류별 가중치(사람 교정 >
  실사용 피드백 > 세션 증류 > 수입 > 에이전트 추론). 위계는 서열이
  아니라 가중치 — 면책 특권 없음(무검증 자동 승격 금지). 선호 교정은
  사용자가 구성적 원천(교정=개정 선언), 세계 사실 교정은 최강 증거
  (검증 경유).
- **K3 저장은 비용, 회상이 가치** — 회상 안 되는 지식은 부채(토큰·순위·
  주의 오염). 감쇠 저항은 빈도 + 최고 기여도(저빈도 고가치 보호).
  안 쓰임 ≠ 낡음 — 별개 회로.
- **K4 진실의 수정은 무효화(append-only)** — 과거의 틀림도 데이터.
  K4는 인식론적 수정(무효화·선행 관계 보존)만 지배 — 존재 제거(보안·
  프라이버시 expire)는 별개 레지스터. 현행 실현(UPDATE 금지·supersede·
  bi-temporal·dolt 감사)의 명문화.
- **K5 사실은 조건·출처·시점과 한 몸** — 맥락 없는 사실은 버그 발생기.
  조건 평가는 재점검 큐에서만(회상 시점 평가는 P1 위반).

귀결: K1·K2 → §4 교정·환류·모순 감지 / K3 → §5 병합·감쇠 개량 /
K5 → §5 조건 태그·provenance / §6 만남 순간 판정은 P1·K2의 실현
형태 / K4는 기준점(신규 개발 불필요).

## 4. 교정 플로우 — 입구·처분 (K2 분기 반영)

- **감지 경로 후보** (비간섭·프라이버시 전제, 택일 보류)
  - A안: 어댑터 훅 확장(사용자 프롬프트 계열 훅) — 교정 후보만 최소
    추출, 전체 발언 캡처 금지. 하네스별 가용 훅 차이 조사 필요.
  - B안: 에이전트 계약 유도 — 교정 인지 시 즉시 `flint write`(신규
    source) 적립. 구현 최소·어댑터 무관, 에이전트 순읬도가 품질 결정.
- **처분 분기(신설, 2026-11-20)** — K2 선호/사실 이원화의 구현
  - 선호 교정 → **즉시 개정**: 신규 적립 + 구 항목 supersede(사용자
    선언 자체가 원천 — P2·K2).
  - 세계 사실 교정 → **검증 경유**: pending 적립(최강 증거 가중) 후
    승격. 잘못된 교정 1건의 오염(gaslighting 벡터) 차단.
  - 교정 표적 식별은 §6 쓰기 echo의 근사 이웃으로 탐색.
- **구조 원칙(공통)** — 입구 다각화·종점 수렴: 모든 케이스는 공통
  종점(pending → approve)으로 모이고, 4연산·content_hash dedup·승격
  회로는 재사용. 케이스 정의는 코드 등록표 단일 소스(단일 소스 + 동질
  가드 준용). source 채널 확장도 등록표에서.

## 5. 낡은 지식 감지·변동성 계층 (2026-11-20 편입)

- **낡음 신호 5종** (증거 누적 — P1): ①모순 발화(신규 적립과 충돌)
  ②bad_recall(회상했는데 틀림 — G6 관측 자산) ③사용자 교정 표적
  ④TTL 경과(계층별 유효기간) ⑤근원 변화(옵시디언 원본·git·import
  원본 해시 — flint는 인덱스 계층이므로 원본-파생 불일치 = 낡음).
- **처분**: 자동 삭제 없음. `maintain --stale-audit` 승인제(decay-audit
  패턴) → supersede / expire / **재확신**(유효기간 리셋).
- **변동성 3계층** — 불변(역사·ADR 사실 — 감쇠 면제) / 조건부(선호·
  관례) / 휘발(버전·경로·도구 상태). 분류는 출처·주제 기본값 + 개별
  오버라이드(행마다 판단 안 함).
- **조건 태그** — "어떤 조건에서 유효" 명시(예: 엔진 미지원인 동안).
  조건 파열 시 재점검 큐 — 낡음 감지가 추측에서 점검 가능한 트리거로.
- **감쇠 개량(K3)** — 저항 = 빈도 + 최고 기여도. 불변 계층 면제로
  "잘 안 불리는 영구 참"의 아카이브 결함 해소.
- **후속 보완 후보** — 유사 병합 merge-audit(정확 hash만 잡는 dedup
  사각 — top-k 오염·토큰 낭비)·환류 일반화(bad_recall→지식 상태)·
  relations 이웃 회상(`read --related`)·회상 근거 표시(`--why`).
  모순 사전 감지·병합 후보 발굴은 §6 쓰기 echo로 실현.

## 6. 만남 순간 판정 — 쓰기 echo·회상 플래그 (2026-11-20)

원리: 판정의 진짜 비용은 연산이 아니라 **문맥 재구축**. 쓰기·회상
순간에는 판정에 필요한 문맥이 무료로 존재하므로 그 순간 흡수하고,
배치(census)는 잔여 부채만 청소한다 — "태어날 때 심사받고, 자면서
나머지를 정리". 우아함 준거: 신규 부품 0·판정 1회(같은 질문을 두 번
안 묻기)·수축하는 배치. 목표 측정치는 "KB 신뢰 유지 한계비용이
시간에 따라 감소".

- **쓰기 echo(핵심)** — write 파이프라인(검증 → hash dedup →)에
  근사 스캔 단계 삽입: `lib/query/suggest.go` bigramDice(NFKC rune
  bigram Dice)·자모 bigram 재사용 — read 회상 엔진과 동일 스코어.
  응답에 근사 이웃 상위 k(id·스코어)를 첨부하면 작성 에이전트가 그
  순간 NOOP/ADD/UPDATE+supersede를 판정(쓰기 3계층과 동일 — 판정
  우선순위 NOOP>삭제>갱신>추가는 Mem0 관례와 같은 방향, 계약
  명문화). 단일 메커니즘이 dedup·모순 사전 감지·병합 후보 발굴·
  교정 표적 식별 4표면을 지원. 조사 확인: related-on-write(쓰기
  응답 유사 항목 반환) 선행 사례 미발견 — flint 신규 기여.
- **지연 JOL 규칙** — 즉시 판정은 과신(지연 판단이 더 정확하다는
  메타기억 연구 확립 — §11). echo 산출은 후보 제안 한정, 확정은
  지연(승인·재점검 경유).
- **회상 건강 플래그** — read 응답 행별 age·저회상·stale 증거 점수
  부여 → 사용 중 환류(G6 bad_recall 회로 재사용).
- **census(에이전트 전수조사) — 잔여 청소로 축소** — 장기 미사용
  행 순회·레거시 import 정리. 5단계: 결정론 후보 수집 → 지시서(청크·
  체크포인트·판정 계약) → 에이전트 판정 → 게이트 검증(산출 JSONL·
  exit 3 자가수정) → 승인·감사(소스 마킹으로 라운드 일괄 무효화).
  통제 장치: 블라인드 데코이(정상 답 NOOP인 통제행 주입 — 라운드
  품질의 결정적 계량)·쿼럼/티어링(고위험 연산 영구 사람 승인)·판례
  (census 판정 자체를 지식행 적립 — 모델 간 안정 앵커)·NOOP 사전
  명시·인사이트 생성 기본 비활성.
- **스케일 아웃** — 현 규모(수천~수만 행) bigramDice 전스캔 Go
  밀리초급. 10만 행 접근 시 행별 MinHash 스케치 저장(후보
  ekzhu/minhash-lsh). SimHash(부분 겹침 약함)·Bloom(유사도 판정
  불가) 부적합. 지표는 PERF 문서로.
- **관계 어휘 확장 검토** — Oracle AI Agent Memory 26.8의 타입 관계
  5종(supersedes·refines·supports·contradicts·duplicates) 참고:
  모순 감지=contradicts·병합=duplicates 관계로 표현.
