## 3. 요구사항

### R1 flint help
- `flint help` 서브커맨드 — 기존 no-args usage 문구 + 명령별 1줄
  요약 출력, exit 0. no-args 동작 불변. 인자 있으면 무시(help는
  인자 없음).

### R2 dup 소스 분리 계측
- write 파이프라인의 duplicate 계측이 기존 총계 `dup`에 더해
  `dup_<source>`(hook·manual·mcp) 일별 카운터를 증분(총계 불변·
  additive). report 일별 행에 `dup_hook`·`dup_manual`·`dup_mcp`
  필드 추가(미기록 일 0), report 출력 말미에 기간 합계
  `dup_hook`·`dup_manual` 2필드 추가(기존 필드·순서 불변).

### R3 doctor backup-age 서브셋
- `flint doctor --check backup-age` 단독 실행 지원 — tail-chain
  검사도 서브셋 이름 매칭에 포함. 기존 검사 순서·DoctorChecks()
  계약 불변. 미지정 검사명 동작(안내) 불변.

### R4 문서 소급·SKILL 플래그
- PLAN.md §14에 v0.9.4(훅 자가수복·PR #12)·v0.9.7(전파·이전
  정리·PR #15) 마일스톤 소급 기록(시간순 위치·기존 절 불변).
- flint-plugin/skills/flint/SKILL.md 명령 요약에 `--status`·
  `--kind`·`--limit` 문서화. 머지 후 코디네이터가
  `setup --update-rules` 재싱크(운영).
