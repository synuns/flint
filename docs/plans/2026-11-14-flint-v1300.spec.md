   txt(LLM 주입·grep)·csv(목록 인덱스 — content 제외). 조사 근거:
   노트앱 교환 표준=md, 에이전트 메모리 표준 포맷 부재, txt·csv는
   Notion/Obsidian 관례.

4. **flint import 마이그레이션:** `--format jsonl`(왕복 재이식·id 보존·멱등)·
   `--format pam`(PAM v1.0 수입 — pending 적립·승격 모델 준수). 기존
   규칙 import 불변.
