## 2. 설계

### 2.1 render 코어 (lib/cli/render.go 신규)

- `render.Text(s string) string` — store.SanitizeText 위임(출력용 단일 출구)
- `render.Masked(s string) string` — MaskSecrets→SanitizeText 순서 보존
  (brief 계약, ADR-0015)
- `render.Rows(rows [][]any, fields string, jsonMode bool) string` —
  셀 전수 살균 후 query.FormatRows 위임(read·hot 셀 루프 대체)
- `render.Cells(rows [][]any) [][]any` — 셀 살균만(포맷은 호출자)
- e.g. render.Text("a[flint]b") -> "a b" · render.Rows(2행, "topic,summary", false) -> 포맷된 2행 문자열(셋 전부 살균)
