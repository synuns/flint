# ADR-0017 — 자율 튜닝(guarded autonomy) 도입 — 완전 자동화와 방어 장치

- **상태**: 채택(2026-11-21) — 구현 전 기획 확정(docs/plans/2026-11-19-flint-knowledge-pipelines.md §12)
- **맥락**: 튜닝 워크플로우 점검(2026-11-21) — 관측·경고는 자동
  작동하나 조정 실행이 실전 휴면(경고 반복에도 오버라이드 발생
  사례 없음), 후검증 도구 부재. 건별 사람 승인(제안 회로 중간안)은
  루프를 닫지만 매번 승인의 비용이 남고, 인과 증명은 단일 로컬
  DB(n=1) 구조상 불가능.
- **옵션**: ① 건별 승인 제안 회로 ② 관측·보고만 유지(현행)
  ③ 정책 위임 자율 튜닝(채택). ①은 편의 미달, ②는 점검이 반증(루프
  휴면), 무제한 자동은 잘못된 조정의 오염(가스라이팅 벡터) 방어 불가.
- **결정**: 4계층 guarded autonomy — 정책(사람·한 번: 자동 가능 키
  화이트리스트·키별 안전 범위·비율 한도·킬스위치) / 실행(신뢰 사다리:
  shadow 모의 → 예측 적중 누적 시 저위험 키부터 적용) / 검증(독립
  지표 쌍 — 경고 소멸만으론 성공 아님, 증상 마스킹 적발·자동 복원·
  센티넬·위반 반복 시 자기 비활성화) / 투명(tuning log·nudge 요약).
  튜닝값은 기존 meta 오버라이드 경유만(thresholds.go 기본값 불변,
  자동 대상은 등록 키 한정). METRICS §5 금지 5의 예외 조항을 이
  ADR로 명문화 — 에이전트 표면 간섭(차단·주입 강화) 금지와 비간섭
  5원칙은 그대로 유지된다(자율 조정은 flint 자기 민감도 한정).
- **되돌림 트리거**: 자동 복원이 적용의 과반을 상습 차지하거나 증상
  마스킹이 반복 적발되면 자율 등급을 축소(shadow로 강등)하거나
  폐기한다. 사람 판단이 자동보다 나은 영역으로 판명되는 경우 포함.
