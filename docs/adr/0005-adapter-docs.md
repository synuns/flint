# ADR-0005: 하니스 어댑터 형태 = MCP 가이드 문서 + 프롬프트 스니펫

- 상태: 채택 (2026-10-22, v0.3)
- 맥락: Hermes 카탈로그·OpenClaw 어댑터의 구체 형식 미정(기획 §14 v0.3).
- 옵션 대조: ①문서 어댑터(MCP 참여 가이드+하니스별 프롬프트 스니펫) ②하니스 전용 스킬/플러그인 파일 생성 ③코드 수준 통합.
- 결정: ① — 기획 원칙 "훅 없는 하니스는 MCP 도구만으로 참여"(§13)에 정합, 구현 부담 최소, flint mcp가 단일 인터페이스(§12 표준 계층)로 유지됨. ②는 각 하니스 형식 추적 비용, ③은 비목표 범위 확장.
- 되돌림 트리거: 특정 하니스 사용 빈도가 높아지면 ②로 승격.
