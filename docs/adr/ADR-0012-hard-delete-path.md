# ADR-0012: 하드 삭제 경로 = 백업 재구축 (v0.26.0)

- 형식: ADR (조사 확정 — 구현 이연)
- 날짜: 2026-11-08
- 상태: **경로 확정·구현 §15 이연**

## 배경

마일스톤 F의 선택 삭제·스크럽은 무효화(soft)가 아닌 하드 삭제를
요구한다. Doltgres 공식 문서 전수 조사로 이력 재작성 가능성을 확인했다.

## 조사 결과 (2026-11-08 심층 레퍼런스 조사)

1. **DELETE는 이력에 남는다** — `AS OF 'HEAD^'`·`dolt_history_*`로
   삭제 전 행 조회 가능(시간여행은 flint의 핵심 기능이기도 하다).
2. **`select dolt_gc`는 미참조 청크만 정리** — 커밋 도달 가능
   데이터 유지(GC 정의상 추론 — 문서 미명시).
3. **filter-branch 대응물 없음** — SQL 함수 문서 전수 확인.
   최근접은 DOLT_REBASE(interactive only)·DOLT_RESET.
4. DOLT_PURGE_DROPPED_DATABASES는 DB 단위만.

## 판정

Doltgres에서 이력 재작성 경로는 사실상 부재. 하드 삭제의 유일한
실현 경로는 **백업 재구축**: dump → 대상 id 필터 → 새 DB 재생성
(기존 Dump/Restore 인프라 재사용). 전체 재작성 비용 + 운영 DB
교체 위험성 때문에 별도 마이너로 이연한다(트리거: 하드 삭제
수요 실증 — 개인 데이터·규정 요건).
