# ADR-0006: 메모리 오염·비밀 유출 구조적 방어

- 상태: 채택 (2026-10-22, v0.4)
- 맥락: 기존 방어가 규칙 문서뿐(주입=데이터 규칙). 메모리 포이즈닝(MINJA·Unit 42·MemoryGraft — 저장된 내용이 나중에 신뢰되는 지속 위협)과 비밀 유출(DB→백업 경로)이 실증된 위협.
- 결정: ①입·출력 살균(제어 문자·[flint] 마커 위조 제거)+비밀 패턴 스캔 경고 ②백업 sha256 사이드카+restore 검증 ③origin 필터·분포 노출. 저장 거부가 아닌 경고+살균 — 신뢰 경계는 가시화로 유지(confidence는 품질 필터지 보안 아님, §11).
- 기각: 저장 완전 차단(운영 마찰)·자체 LLM 검열(비용·오탐).
- 되돌림 트리거: 오탐 다발 시 패턴 표 조정.
