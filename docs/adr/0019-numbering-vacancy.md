# ADR-0019: 결번(편성 단계에서 소멸)

- **상태**: 번호 유지·내용 없음 (2026-11-24 소급 기록, v1.32.0)
- **배경**: v1.29.0 편성 과정에서 ADR-0019 자리에 임시 항목이
  존재했다가 승인 전 편성 단계에서 소멸했다. 그 내용(전용 테스트
  엔진 포트 5499 예약)은 ADR-0020의 호스트 포트 결정에 승계되어
  인용되고 있다("5499는 제외 — v1.29.0 전용 테스트 엔진 예약,
  ADR-0019 승계").
- **결정**: ADR-0019 번호를 재사용하지 않고 결번으로 유지한다.
  이 문서는 그 사실과 경위만 기록한다.
- **근거**: ADR-0020이 이미 "ADR-0019 승계"를 인용하고 있어 번호를
  새 내용으로 재발급하면 인용이 잘못된 문서를 가리키게 된다.
  결번 유지가 색인 연속성을 지킨다.
- **시행 착오**: 번호를 먼저 배정하고 내용 확정을 뒤로 미루면
  편성 중 소멸 시 결번이 남는다. 이후에는 승인 시점에 번호를
  부여한다.
