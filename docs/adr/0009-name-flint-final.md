# ADR-0009: 이름 flint 최종 확정

- **상태**: 채택 (2026-10-23, synuns/branding)
- **맥락**: ADR-0003(비공개 한정 유지)의 공개 전 재검토 조건이 브랜딩 작업으로
  발동. 2026-10-22~23 전 방향 탐사: knapp 전면 리네임 시도 후 철회(독일어
  "부족한"+성씨, flint 느낌 상실), 이후 충돌 검증 15+ 후보 — agent- 접두
  (agentkeep·agentmem 등)와 memory 직접 은유(engram·mira·aria·hippo·tessera)
  는 전부 직접 경쟁물과 충돌, OMO식 두문자어(arca·aria)도 인접 점령 상태.
  무충돌 생존: 신조 합성어(memdelta·memwright·memkeep)와 희소어(palimpsest).
- **결정**: **flint 유지 확정.** 간접 물질 은유라서 직접 경쟁물과 충돌하지
  않는다는 것이 데이터로 확인됨(동명 레포 7개는 전부 이종 도메인). 충돌은
  포지셔닝으로 해결: 레포 description "Version-controlled memory for AI
  agents…" + topics(agent-memory·mcp·doltgres 등), README 이중언어
  (oh-my-obsidian 포맷) 적용 완료.
- **되돌림 트리거**: 직접 경쟁물이 flint 이름을 취하거나, 상표 분쟁 발생 시.
